User API Endpoints

GET "/"

Provide message about server being online.

GET "/api"

List of endpoints.

POST "/api/auth/signup"

Signup to create a user.

Body: email, password, firstName, lastName

POST "/api/auth/login"

Log in to an existing user account.

Body: email, password

GET "/api/auth/me"

Return logged-in user details (no password).

POST "/api/auth/reset"

Update password for logged-in user.

Body: oldPassword, newPassword

GET "/api/users"

Return list of users.

GET "/api/users/:id"

Return one user.

POST "/api/users"

Add a user (same as signup).

PUT "/api/users/:id"

Update email, firstName, lastName.

Body: email, firstName, lastName

DELETE "/api/users/:id"

Delete a user (not yourself).
